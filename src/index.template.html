04 / Know the coverage
Formats and limitations
Power BI stores different levels of detail depending on the file format. Use a PBIP project containing PBIR and TMDL files for the best results.
Supported inputs
  • PBIP project folder / ZIP: preferred — include the .pbip file and *.Report/definition and *.SemanticModel/definition files.
  • PBIR report ZIP: pages, visuals, filters, bookmarks and report settings.
  • TMDL / model.bim: measure expressions and relationship definitions.
  • PBIX / PBIT: best-effort reading of legacy Report/Layout metadata only.
For a complete project comparison: in Power BI Desktop, save as a Power BI Project (.pbip), enable PBIR and TMDL storage, then select the project folder or upload a ZIP of the complete folder. The .pbip file is a pointer to the report folder, not an archive. An isolated .pbip cannot be compared; select its companion .Report and .SemanticModel folders too. Sample PBIP v1 · Sample PBIP v2.
What this tool cannot guarantee
  • Does not parse proprietary PBIX DataModel binaries or decrypt encrypted archives.
  • Does not compare underlying data values, refresh results, RLS outcomes or visual rendering screenshots.
  • Does not currently perform DAX semantic equivalence or dependency-impact analysis.
  • Renamed object IDs may show as one deletion and one addition.
  • Unknown or missing metadata is marked not verified, never assumed unchanged.
    

    05 / Privacy and control
    Your reports stay on your device.
    The comparison runs entirely inside your browser, with no report upload API, login or analytics. The online interface may request Mightora shared UI assets and branding from external domains. The offline edition is fully self-contained.
    Network transparency
    Online mode fetches official Mightora shared stylesheet/components and third-party YAML dependency; report files and comparison content are never transmitted by application code.
    Refresh to inspect resource requests.
    Independently verify: Press F12 → Developer Tools → Network → enable Preserve log → reload the page → inspect the domains and requests. The on-screen summary uses browser Performance Resource Timing, which can omit some network activity; it is not a security audit.
    Run completely offline
    The downloadable single-page edition embeds its interface, code and styles. It requires no web server, external APIs, tracking or fonts. Double-click its index.html on Windows, macOS or Linux.

    Offline application policy: default-src 'none' with inline styles/scripts only and no external connections. Browser extensions and operating-system services are beyond application control.
    

    06 / Common questions
    Power BI diff FAQ
    

    How do I compare two Power BI reports?
    Save the earlier and later Power BI projects in PBIP format. Select their project folders or ZIP archives above, click Compare, then browse the change list or download release notes.
    

    Can this compare DAX measures?
    Yes, when TMDL table definition files or a model.bim semantic model are available. Traditional PBIX DataModel binaries cannot be decoded by this static application.
    

    Are report files uploaded to a server?
    No. Your browser reads them locally. The online site loads public UI assets, but its application code does not send report contents to any remote endpoint.
    

    Can I compare PBIX files?
    Best-effort comparison is available for readable legacy Report/Layout metadata inside PBIX/PBIT ZIP archives. For accurate measure and relationship comparisons, save your reports as PBIP projects with semantic model metadata.
    

    Does it produce release notes?
    Yes. The Markdown release notes group added, modified and removed changes by area and record all unsupported comparison categories. You can also export HTML and structured JSON reports.
    

    Does the offline edition need installation?
    No. Download the single HTML file or extract the ZIP, then open index.html directly in a modern browser. No installation, local server or internet access is needed.
